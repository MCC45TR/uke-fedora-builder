Senemos Linux for Xiaomi Pad 7 / POCO Pad X1

Development packages for the Qualcomm SM7675 platform (device code: uke).
Target: Fedora Rawhide AArch64. Updated: 14 October 2026.

This repository provides the Senemos kernel, boot integration, hardware-support
metadata, reviewed native runtime libraries and optional desktop components.
The separate KVM package is experimental; it does not establish EL2 boot or
working hardware virtualization. KDE applications come from Fedora.

Recovery RPMs deliver checksummed preview images and source/license records as
data. Package installation never flashes Android partitions or selects a boot
slot. ZIP installation and recovery compatibility require their own checks.

Build results establish package status. Hardware support, stability, charging
and power management are tracked separately in the public hardware report.
RPM versions follow upstream versions with numeric release counters; device
identifiers remain in device package names. Python-based upstream build tools
are confined to build workers and excluded from project target payloads.

This is a development repository. Preserve a tested Android/recovery fallback
and use packages only with their matching kernel, modules, device tree and
firmware requirements.
