Senemos Uke — source builds and update channel
============================================

Development RPM/SRPM hub for Xiaomi Pad 7 / POCO Pad X1 (Uke, SM7675).
**Enabled target: Fedora Rawhide AArch64.**

**Kernel and recovery**

- `senemos-uke-linux-kernel-mainline` 7.2.9-1.3: matching core/modules/DTBs,
  verified upstream signed source, seven Uke adaptation patches and separate
  configs. Native signed build 11075043 passed Image/DTB, 1,146 module ABI/
  dependency checks and actual fresh-install/1.2→1.3-upgrade/removal tests.
- `uke-orangefox-recovery`: checksummed IMG/ZIP, source/license/firmware-profile
  records, updated through DNF as data. The current image is the published
  Global OS3 alpha. It has no scriptlets, flashing service or automatic installer.

**Screenshot counterpart packages**

- `uke-core-meta`: native console selection; signed dependency transaction,
  verification, Python solver guard and removal passed.
- `uke-desktop-metas` / `kde-plasma-uke-meta`: explicit stock-Plasma selection
  requiring reviewed native runtime variants. Complete corrected desktop
  acceptance is tracked separately from native RPM compilation.
- `material-decoration`: published stable upstream C++/Qt6 decoration and KCM;
  native AArch64 plugins and signed extracted payload checks passed.
- `plymouth-uke`: original optional theme using current renderer dimensions;
  installation does not select a theme, regenerate initramfs or change boot.
- Six exact official Fedora source variants: at-spi2-core, GStreamer,
  libaccounts-glib, libwacom, Plasma workspace and Dolphin. Optional Python
  tools/bindings are excluded; required configuration migrations use C++.
  See the current desktop report for package and whole-runtime gate results.

Twelve real source families have automatic builds. GitHub push hooks and an
explicit shared-native-source workflow request builds; daily kernel, Material
and recovery workflows inspect eligible stable sources. Unreviewed kernel
versions stop before any generic ARM64 fallback. Native Fedora recipe updates
need reviewed source/tool pins. Source workers fetch verified archives; binary
workers have network disabled. Healthy build jobs are preserved.

**Admission and hardware boundary**

The firmware repository is published, but no `xiaomi-uke-firmware` RPM is admitted
without per-file Uke provenance, SHA-256, redistribution rights and matching
kernel requests. Sensor, camera, platform, boot and hardware-integration initial
repositories retain explicit source/physical gates. Fedora's PowerDevil and
Plymouth engines remain shared dependencies; Nabu board patches are not copied.

This channel certifies the recorded build/package states only. It does not
certify UEFI firmware, firmware-specific RAM handoff, a bootable composed tablet
image, physical boot, rollback, graphics or peripherals. Kernel/recovery package
installation never writes Android partitions or selects a default boot target.
Tested kernel/recovery/console closures exclude Python. The original complete
Plasma transaction was rejected for Python; corrected closure acceptance is
reported independently. No generic userspace `kernel-headers` is replaced.
