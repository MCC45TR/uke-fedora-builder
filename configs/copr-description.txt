Senemos Uke — source builds and update channel

Development RPM/SRPM hub for Xiaomi Pad 7 / POCO Pad X1 (Uke, SM7675).
Enabled target: Fedora Rawhide AArch64.

Kernel 7.2.9-1.3: signed upstream source, seven attributed Uke adaptation
patches, matching Image/DTB/1,146 modules. Native signed build 11075043 passed
ABI/dependency, fresh-install, actual 1.2-to-1.3 upgrade and removal checks.
UEFI firmware and physical tablet boot remain independent gates.

Recovery: uke-orangefox-recovery delivers the published, checksummed Global
OS3 alpha IMG/ZIP and source/license/profile records as DNF-updated data.
No flashing scriptlets, automatic ZIP installer or Android partition writes.

Core and desktop policy metadata: console-first selection, explicit readiness
records, no graphical session installed. The owner forbids cloning, forking or
rebuilding KDE desktop applications. Use original distribution KDE packages.
Plasma/Dolphin derivative source records and binary builds were withdrawn.
Original KDE Python payloads currently block complete graphical admission.

Material Decoration: explicitly requested stable upstream C++/Qt6 plugin;
signed native payload/ELF checks passed. Plymouth-uke: original optional theme
data, sized by the renderer, without activation or initramfs regeneration.

Eleven real source families have automatic builds. Five non-KDE native source
families cover at-spi2-core, GStreamer, libaccounts-glib, libwacom and GNU
libstdc++. Reviewed sources exclude optional Python tools. GNU C++ requires the
complete original 6,100-symbol ABI and native smoke test; build 11077014 passed.
The separate 52-input signed console selection passed offline fresh installation,
actual metadata upgrade, full inherited-root audits and removal. Initial core
installation explicitly allows the reviewed Fedora-to-COPR library vendor
change. A historical 603-input desktop
transaction passed bounded payload/lifecycle checks but its complete root
failed on inherited Python debugger helpers; that root remains rejected.

GitHub push hooks and shared-source workflows request native builds. Daily
kernel/Material/recovery trackers inspect eligible published stable releases.
Unreviewed kernel versions stop before generic ARM64 fallback; recovery requires
approved firmware/asset/source identities. Binary workers have network disabled.

Hardware components share the uke-linux-hardware-support source repository
and retain explicit admission gates.
No firmware RPM until every Uke file has approved provenance, redistribution
rights, hashes and matching kernel requests. Nabu geometry, firmware and
hardware assumptions are not portable. No composed tablet image or physical
support is certified by this channel.
